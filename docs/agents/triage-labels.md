# Triage Labels

The engineering skills use five canonical triage roles. Map them to these issue-tracker labels:

| Canonical role | Tracker label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Maintainer evaluation is required |
| `needs-info` | `needs-info` | Waiting for more information |
| `ready-for-agent` | `ready-for-agent` | Fully specified and ready for an agent |
| `ready-for-human` | `ready-for-human` | Human implementation is required |
| `wontfix` | `wontfix` | Will not be actioned |

When a skill names a role, use the corresponding tracker label from this table.
